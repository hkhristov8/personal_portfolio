# Hristo Hristov - DevOps/Unix Engineer Portfolio

A modern, responsive portfolio website showcasing professional experience, skills, and certifications in DevOps and Unix engineering.

## ✨ Features

### 🎨 Modern Design
- **Responsive Layout**: Optimized for all device sizes
- **Dark/Light Theme**: Toggle between themes with persistent storage
- **Smooth Animations**: CSS transitions and JavaScript-powered animations
- **Interactive Elements**: Hover effects, click animations, and parallax scrolling

### 🚀 Performance & UX
- **Loading Overlay**: Professional loading experience
- **Lazy Loading**: Optimized image loading for better performance
- **Smooth Scrolling**: Enhanced navigation experience
- **Mobile Optimized**: Reduced animations on mobile for better performance

### 🎭 Visual Effects
- **Particle Animation**: Dynamic background with interactive particles
- **Scroll Animations**: Elements fade in as you scroll
- **Floating Certificates**: Subtle animations for visual appeal
- **Gradient Text**: Modern gradient effects on headings

### 🔧 Technical Features
- **Modular JavaScript**: Organized into classes for maintainability
- **CSS Variables**: Consistent theming with CSS custom properties
- **Semantic HTML**: Proper HTML5 structure for accessibility
- **Cross-browser Support**: Modern CSS with fallbacks

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript (ES6+)**: Modular, object-oriented code
- **Canvas API**: Particle animations

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### Installation
1. Clone or download the repository
2. Open `index.html` in your web browser
3. For development, use a local server to avoid CORS issues

### File Structure
```
personal_portfolio/
├── index.html          # Main HTML file
├── styles.css          # All CSS styles
├── script.js           # JavaScript functionality
├── contacts/           # Contact information and images
├── companies/          # Company logos
├── technologies/       # Technology stack icons
└── certifications/     # Professional certificates
```

## 🎨 Customization

### Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #00ffff;      /* Main accent color */
    --secondary-color: #ff00ff;    /* Secondary accent */
    --accent-color: #ffff00;      /* Highlight color */
    --bg-primary: rgba(0, 0, 0, 0.95);    /* Background */
    --text-primary: #ffffff;      /* Main text color */
}
```

### Animations
Adjust animation speeds and effects in `script.js`:
```javascript
// Particle count
this.numParticles = 1500;

// Animation speed
this.time += 0.002;
```

### Content
Update the HTML content in `index.html` to reflect your information:
- Personal details
- Work experience
- Education and certifications
- Skills and technologies
